# Lyrion Weather Alerts

A Lyrion Music Server plugin that will play National Weather Service alerts on Squeezeboxes, then restore what was playing.

**Status: early skeleton.** It installs and has a settings page. It does not watch for alerts or play anything yet. Don't rely on it for safety.

## Install

1. In Lyrion, open Settings, then Plugins.
2. Under Additional Repositories, add this URL and save:

   `https://raw.githubusercontent.com/gitdrk/lyrion-weather-alerts/main/repo.xml`

3. Enable Weather Alerts in the plugin list and restart when asked.
